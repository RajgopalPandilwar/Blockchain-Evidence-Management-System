# Blockchain Evidence Management System

An evidence management system leveraging blockchain technology for secure, tamper-proof storage and tracking of digital evidence.

## Overview

This project demonstrates how blockchain technology can be applied to evidence management in legal and forensic contexts. It ensures evidence integrity, chain of custody tracking, and tamper-proof audit trails.

### Youtube Video : https://youtu.be/h2naWQ2lFa0?si=Fa27pXiRA_Yul5W0

## Features

- Secure evidence recording on blockchain
- Tamper-proof audit trail
- Chain of custody tracking
- Evidence verification via cryptographic hashing

## Tech Stack

- Blockchain concepts
- Cryptographic hashing (SHA-256)
- Web-based interface

## How It Works

1. Each piece of evidence is recorded as a block
2. Blocks are cryptographically linked to previous blocks
3. Any tampering with evidence data breaks the chain
4. Full audit trail is maintained for legal compliance
